Privacy Policy

Soul Of Ubuntu · Effective date: September 6, 2026

This Privacy Policy explains how the Soul Of Ubuntu Pinterest integration ("the application") accesses and uses information from the Pinterest account it is connected to. This application is a personal automation tool operated by the owner of the Soul Of Ubuntu YouTube channel and its associated Pinterest account, used solely to publish that channel's own content.

Information We Access

When the Pinterest account owner connects this application via Pinterest's OAuth authorization flow, the application requests access to:

  • The authenticated account's own boards (to select where to publish content)
  • The authenticated account's own pins (to create new pins and avoid publishing duplicates)
  • Basic account information needed to establish and maintain the connection

The application does not access, read, or collect data belonging to any other Pinterest user, board, or pin outside of the connected account.

How We Use This Information

Information obtained through the Pinterest API is used exclusively to:

  • Create and schedule pins on the connected account's own boards, linking to the Soul Of Ubuntu YouTube channel's content
  • Read the connected account's existing boards and pins to choose a publishing destination and prevent duplicate posts

We do not use this information for advertising, profiling, or any purpose unrelated to operating this channel's own Pinterest presence.

Data Storage & Security

Authorization tokens are stored in an encrypted local credential store on infrastructure controlled solely by the application operator. Tokens are never transmitted to, or shared with, any third-party service or party. No Pinterest data obtained through this integration is sold, rented, or shared with third parties.

Data Retention

Access tokens and related connection data are retained only for as long as the Pinterest account remains connected to the application. The account owner may revoke access at any time from Pinterest's own account settings ("Apps" section), which immediately invalidates the application's access.

Your Rights

As this application only ever operates on an account the operator directly owns and controls, there is no separate end-user data subject to third-party rights requests. The account owner can disconnect the application at any time via Pinterest.

Changes to This Policy

This policy may be updated from time to time to reflect changes in the application's functionality. The effective date above will be updated accordingly.
